## 边界

- 外部MCP为明确配置的可信服务；默认逐次确认，可按工具授权自动调用。
- Skills仅文字指令，不执行脚本和附带资源。
- 暂不支持OAuth交互和旧SSE传输。
- 引用检查验证ID来自本轮读取资料，不能证明生成结论被原文语义支持；外部工具结果仍需核实。
- 模型工具选择仍可能失误；失败/拒绝/达到执行额度会显示限制，不保证所有任务自动完成。
