# JobScope 对话隔离与分页UX调整

依据用户明确需求，保留已确认的unslop视觉方向；使用Product Design audit检查现有流程后实施。

审查证据：`jobscope/output/ux-audit/01-before-jobs.png`、`02-before-library.png`。岗位页只有摘要却提供适配按钮；公司资料库一次渲染598条档案，筛选输入同时控制对话范围；公司/岗位/全局范围缺少明确层级，后台更新没有同步到旧页面。截图可证明布局和入口问题，不能证明服务端隔离或无障碍合规，需测试。

设计：岗位研究保留主从结构，岗位列表20条/页；详情来源10条/页；公司库将来源档案与公司对话分成标签，确认公司后锁定对话范围，允许从资料行选择公司；全局问答独立导航，明确检索全项目已保存证据。公司主体使用精确名称，不自动合并子公司或品牌。来源、任务均服务端分页，显示总数、当前页和前后页按钮，查询条件改变回第一页。

服务端会话绑定范围，历史由后端保存和读取；客户端提供的跨范围历史不进入模型。公司检索先按主体限制，再检索；全局显式授权范围后可检索所有已保存证据。引用带公司主体与来源。测试验证同名/相似名不串库，切换公司及异步返回不串话。
