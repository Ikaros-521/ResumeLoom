# JobScope 完整JD补采实施计划

用户明确要求补全岗位职责，用于判断是否适合投递。沿用已经授权的项目浏览器和299条BOSS岗位。

目标：保存真实详情正文、来源与读取时间；支持单条和后台批量补全、跳过已完成项、验证时停止并保留进度。BOSS列表摘要不得进入适配分析。公司自述分开保存，不作为独立业绩证明。

架构：`job_details.py`负责限定BOSS原始岗位URL、读取详情DOM、校验岗位身份并归一化；仓库负责正文快照、防止后续列表采集降级；FastAPI提供单条和后台批量接口，任务表持久记录进度；前端展示正文状态、单条补全及批量进度。

技术：现有FastAPI/SQLite、DrissionPage、React/TypeScript，无新增依赖。
