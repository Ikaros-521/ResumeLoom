# 简历文件导入

用户要求：我的简历支持 PDF、Word 等文件，自动提取文本。

## 交互与存储

在简历编辑区上方提供文件选择和拖入入口。支持 pdf、docx、txt、md、yaml、yml。提取后显示文件名、字数、页数、只读预览及阅读顺序提示。用户应用到编辑区后可修改，沿用原保存按钮。取消或失败保留原内容，提取接口从不修改数据库；保存前的提取文本不参与适配分析。原文件不落盘、不上传外部服务。

## 解析

POST /api/resume/import?filename=... 接收原始文件体。10 MB 流式上限，线程池内解析，响应包含 text/format/characters/pages/warnings。PDF 复用 PyMuPDF，最多 50 页，按页排序提取；纯图片 PDF 拒绝并说明 OCR；混合 PDF 标明未提取文字页，保留提醒。Word 直接读取受限 ZIP 中的 document.xml、header/footer XML，按顺序保留段落/表格/文本框文字，排除已删除修订；不执行外部关系、宏或嵌入对象。限制 1,000 个压缩条目、解压后 20 MB。文本支持 UTF-8 BOM、UTF-16 BOM、GB18030。提取结果最多 100,000 字符，超过时明确拒绝而非静默截断。facts.yaml 复用结构校验。

旧二进制 .doc 没有可用的本地转换器，此版明确引导另存为 .docx。扫描件 OCR 不在此版中，界面明确说明。原有请求体上限仅为文件导入路径放宽，来源保护继续适用。

## 验证

解析测试覆盖 PDF/Word 正文表格页眉、被删修订、扫描件、加密、损坏格式、中文编码、facts、文本及文件限制、ZIP 解压限制，且导入不改原简历。浏览器验收覆盖 PDF 上传预览、应用后才替换编辑区、显式保存、失败和取消保留、Word 预览与手机布局。

## 验证结果

- 前端构建通过。
- 全量后端回归 157 项通过（417.27 秒）。审查修复后，导入和 API 相关测试 32 项通过（113.20 秒），含新加的 Word AlternateContent、深层 YAML、损坏压缩流及 UTF-16 DTD 回归。
- 最终浏览器验收通过 PDF/Word 上传预览、应用编辑区、保存、取消与失败保留、手机布局，无页面异常。
