# 全局通用 Agent 与扩展

用户要求：全局对话增加通用 Agent，可接 MCP 与 Skills。

## 产品流程

全局对话保留资料研究模式，新增通用 Agent 模式。切换模式新建独立会话。公司与岗位对话仍用原 ResearchAgent，只检索其限定数据，不加载扩展。全局通用模式允许一般问答、写作、面试准备与工具协作，无须先命中项目证据。

全局页折叠的“Agent 扩展”提供 MCP 增删改、测试发现、连接启用、逐工具允许调用和自动执行授权。远程连接使用 Streamable HTTP 和可选 Bearer Token；本地 stdio 使用可执行命令、JSON 参数数组和环境变量。保存不启动命令，测试会访问服务或启动进程。认证不回读，配置变更重置工具授权。

导入 SKILL.md 文件或粘贴内容，读取 name/description 元信息并保存。目录进入系统上下文，需要时 skill_read 加载正文。只支持文字指令，不执行脚本、不解析附带相对资源，界面说明该范围。

## 执行架构

原生 OpenAI tool_calls / Anthropic tool_use 通过统一 canonical message adapter 适配。通用循环最多8轮模型、12次工具、48000字符工具结果、240秒主动执行，单个MCP操作35秒。模型看工具定义、调用、读取结果后继续选择或最终回答。记录动作与耗时，不记录内部思维链。

内置工具：project_search、project_read（正文分页）、project_salary（全筛选集聚合）、resume_read（确认事实）、skill_read。项目引用仅允许本轮工具实际读取的证据ID，语义支持关系仍需核对。外部工具结果为不可信数据，内容不自动写入项目证据库。

MCP 使用官方 Python SDK 初始化、分页列工具和调用；stdio 隐藏进程窗口并由 SDK 清理子进程；HTTP 不跟随重定向、不用系统代理。最多12连接、每连接50工具，总模型目录40工具（含5内置）。Schema有长度/深度限制，支持本地$defs引用，使用离线Registry，拒绝外部/动态引用及$id重定位。

## 确认与隔离

工具默认逐次确认，可由用户明确授权某工具自动执行。确认显示服务/工具及实际参数，绑定随机 approval_id、run ID、参数状态与配置指纹，事务单次领取，防重复确认跨调用重放。确认有效期1小时，等待用户时间不计入主动执行时限。已读简历会话持久标记，后续外部调用仍强制确认。拒绝或工具失败将作为工具结果返回模型继续，配置变更使旧授权失效。

模型配置每请求快照；跨确认阶段核对原配置指纹，凭证和环境变量不进模型。MCP内容中的已知凭证会过滤。Skills、工具输出和历史不能授予权限。通用会话标识与资料研究会话不同，范围不匹配返回409。

## 验证

后端覆盖一般问答、项目检索引用、Skills渐进加载、两协议原生调用往返、执行上限、MCP凭证脱敏与工具授权、单次确认及队列防重放、配置变更、简历跨轮标记、拒绝/失败恢复、离线Schema及真实stdio握手调用。

浏览器验收覆盖配置MCP、测试工具、逐工具启用、Skills导入、普通问答、工具确认执行、Skill加载和过程展示、390px布局。无测试配置写入默认工作区；独立8766验收。当前配置的GLM用固定无私人数据探针验证原生工具调用。
