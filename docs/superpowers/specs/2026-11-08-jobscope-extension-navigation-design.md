# Agent 扩展入口与操作流程调整

问题：扩展管理位于全局对话的通用模式中，还需要展开折叠区域；用户无法发现入口，配置表单和工具列表挤在聊天页。

沿用 unslop 指导的灰白界面、深绿动作与状态色。新增常驻侧栏“Agent 扩展”，全局对话在两种模式中均显示“管理 MCP 与 Skills”。单独管理页面默认展示连接或Skills列表，上方有MCP/Skills页签、数量、搜索与添加动作。添加或编辑时才展示表单，可以取消；工作区切换时保留草稿。

MCP连接状态按待测试、待授权工具、待启用、可供Agent使用区分。测试后自动展开工具权限；已完成配置的连接默认收起工具细节，显示授权数量及管理按钮。Skills导入表单按需打开，列表直接提供启停。已有后端接入、授权与执行流程复用。

验收：前端构建；浏览器完整MCP保存/真实stdio测试/工具授权/Skills导入/往返全局对话/逐次确认执行/Skill加载；额外检查独立导航、资料研究模式下的管理快捷入口、搜索、表单取消、390px无横向溢出。使用隔离8766服务，配置未写入默认工作区。
