# 前端模型设置

用户要求前端提供配置入口，直接实施。保持当前中性灰、深绿与纸面表单风格，侧栏新增“模型设置”。对话/分析模型与语义模型分别保存、测试。兼容完整 Chat Completions / Embeddings 端点，本机 HTTP 可用；语义模型还支持离线缓存。

配置持久化在工作区 SQLite，按请求读取快照；已开始的请求不受中途保存影响。统一供对话、问题规划、语义适配和向量提供者使用，不修改进程环境变量。环境变量保留为初始值，已保存设置优先，显式禁用也覆盖环境。

API 只返回 key_set，密钥留空保留、显式清除，不读回原文。密钥保留时任何模式都不能更换原服务地址。输入校验失败不回显原始输入，服务错误不返回供应商原始错误体。密钥存本机不加密，页面明确说明。

连接测试使用草稿和同地址已存凭证，仅发送固定短文本，不读简历/证据、不保存。返回成功、延迟、向量维度或通用错误。前端显示已保存/未保存、连接进度和反馈，请求期间锁定表单。模型保存刷新工作区状态，无需重启。

验收覆盖配置持久化、环境优先级、应用隔离、密钥保留清除与地址绑定、错误脱敏、无效端口、离线模型、草稿测试不修改配置、保存后真实 API 路径调用与手机布局。使用隔离数据和本地虚构模型服务验证，不给默认库写入虚构配置。
